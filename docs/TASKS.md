## Task Template

When adding new tasks, use this format:

```markdown
- [ ] Task title
  - Description: What needs to be done
  - Priority: High/Medium/Low
  - Branch: feature/task-name
  - Related: #issue-number (if applicable)
```

When completing tasks:

```markdown
- [x] Task title
  - Completed: YYYY-MM-DD
  - Version: vX.Y.Z
  - PR: #number
```
